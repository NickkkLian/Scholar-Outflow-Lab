# Imagery and prompt

Reuse the supplied Natural Earth 1:110m world paths. Draw location arcs from four origins to the United States, with no width or volume scale. Rates, intervals and sample sizes come from the existing OpenAlex sample. This is a geographic comparison.

All new illustrations were generated locally as SVG code. Original vector artwork is dedicated to CC0 1.0. The Scholar map boundaries are Natural Earth public domain, inherited from round 2. There is no raster artwork. SVG controls are functional icons.
